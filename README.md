## 🌌 Project Overview

**NEXORA AI** is a cutting-edge artificial intelligence company specializing in frontier cognitive architectures, autonomous neural networks, and multimodal computer vision. This website is crafted to match the design caliber of industry titans such as OpenAI, Anthropic, Scale AI, and Linear.

### ✨ Visual Design & Aesthetic Highlights
- **Deep Obsidian & Cyber Navy Canvas**: Ultra-dark high-contrast palette (`#04060d` to `#070b18`).
- **Luminescent Gradients**: Electric Cyan (`#00f0ff`), Cyber Blue (`#3b82f6`), and Radiant Violet (`#8b5cf6`).
- **Glassmorphism 2.0**: Translucent frosted panels with `backdrop-filter: blur(18px)` and reactive glowing borders.
- **Interactive Neural Constellation Canvas**: Real-time particle connection engine responding dynamically to mouse proximity and screen resolution.
- **3D Holographic Core & Orbitals**: CSS-driven multi-ring orbital rotation and pulsing cognitive center.
- **Interactive 3D Card Tilt**: Subtle perspective shifts on hover for product exploration.
- **Scroll-Triggered Reveals & Animated Counters**: Smooth easing and numerical counters that activate as sections enter view.

## 🛠️ Technology Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Modern Flexbox, CSS Grid, Custom Properties (variables), Media Queries, Keyframe Animations, Glassmorphism (`backdrop-filter`).
- **Vanilla JavaScript (ES6+)**: HTML5 Canvas particle physics, IntersectionObserver for scroll animations, counter easing, form validation.
- **Zero Heavy Frameworks**: No Bootstrap, Tailwind, or React—lightweight, lightning-fast, and natively optimized.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash

git clone https://github.com/dravinalapati/nexora-ai.git

# Navigate into the project directory
cd nexora-ai

# Open in browser (Windows)
start index.html
```
